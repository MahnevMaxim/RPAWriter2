# Правила разбора робота WR (проект только на C#)

- WR — проект Visual Studio на C# без XAML-workflow.
- Точка входа — метод `Main` (обычно в `Program.cs`). Проследуй по вызовам методов от него.
- Каждый значимый метод, выполняющий действие, считай шагом.
- Параметры и возвращаемые значения методов фиксируй как входы/выходы.
- Игнорируй инфраструктурный и служебный код (настройка логирования, DI, сгенерированный код).
