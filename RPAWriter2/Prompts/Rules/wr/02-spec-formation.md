# Правила формирования ТЗ для WR (проект только на C#)

- Восстанавливай техническое задание (ТЗ) в виде JSON с полями `name`, `description`, `steps`, `inputs`, `outputs`.
- Поля `description`, `steps`, `inputs` и `outputs` пиши на русском языке.
- Каждый элемент `steps` описывает один метод/действие в порядке вызова от `Main`.
- `inputs` — параметры методов и читаемые файлы; `outputs` — возвращаемые значения и записываемые файлы.
