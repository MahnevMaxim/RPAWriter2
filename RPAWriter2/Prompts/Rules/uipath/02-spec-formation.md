# Правила формирования ТЗ для UiPath

- Восстанавливай техническое задание (ТЗ) в виде JSON с полями `name`, `description`, `steps`, `inputs`, `outputs`.
- Поля `description`, `steps`, `inputs` и `outputs` пиши на русском языке.
- Сопоставляй каждую активность UiPath с бизнес-действием (открыть страницу, заполнить поле, кликнуть элемент, прочитать/записать таблицу, записать в журнал).
- Сохраняй порядок workflow из `Main.xaml`.
- Упрощённые конструкции (`Flowchart` → `Sequence`) отражай в `description`, когда это важно.
