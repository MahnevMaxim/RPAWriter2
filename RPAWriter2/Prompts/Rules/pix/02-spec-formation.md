# Правила формирования ТЗ для PIX (набор XAML-файлов)

- Восстанавливай техническое задание (ТЗ) в виде JSON с полями `name`, `description`, `steps`, `inputs`, `outputs`.
- Поля `description`, `steps`, `inputs` и `outputs` пиши на русском языке.
- Объедини все найденные workflow в один упорядоченный список шагов.
- Укажи в `description`, что исходник — разрозненный набор XAML-файлов без единой точки входа.
