# Правила разбора робота PIX (набор XAML-файлов)

- PIX — это набор XAML-файлов без фиксированной точки входа. Просканируй все файлы `.xaml`.
- Определи каждый корневой workflow и считай его потенциальной точкой входа.
- Распознавай стандартные активности: `Sequence`, `If`, `While`, `ForEach`, `Assign`, `InvokeMethod`, `WriteLine`, `Delay`.
- Извлекай переменные/аргументы и вызываемые методы.
- Перед восстановлением ТЗ сгруппируй файлы по workflow, к которому они относятся.
