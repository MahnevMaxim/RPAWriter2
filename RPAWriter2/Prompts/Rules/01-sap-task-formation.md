# Правила формирования задач, касающихся SAP

- Для каждой задачи, связанной с SAP, указывай в JSON-задаче поля:
  - `sapTransactionCode` — название/код транзакции SAP (например `VA01`, `SE16N`);
  - `sapActionKind` — вид действия: `setup` (настройка и запуск транзакции), `work` (работа с транзакцией), `gettable` (получение таблицы/данных из транзакции).
- Для остальных задач оба поля опускай.

Работа с одной транзакцией SAP разбивается на отдельные типовые задачи по видам действия:

1. **setup** — настройка и запуск транзакции: вход, ввод параметров, настройка, выполнение.
2. **work** — работа с самой транзакцией: обработка данных, навигация по экранам, ввод/чтение информации, закрытие.
3. **gettable** — получение таблицы/данных из транзакции: выгрузка/чтение результата в таблицу.

Помимо этих типовых подзадач при необходимости добавляются и другие (обработка данных, выгрузка/сохранение результатов, интеграции/передача данных, сверки, прочее).
