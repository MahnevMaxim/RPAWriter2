# Правила формирования ТЗ для MWF (Windows Workflow Foundation)

- Восстанавливай техническое задание (ТЗ) в виде JSON с полями `name`, `description`, `steps`, `inputs`, `outputs`.
- Поля `description`, `steps`, `inputs` и `outputs` пиши на русском языке.
- `name` — имя робота (имя папки/проекта).
- Каждый элемент `steps` описывает один бизнес-шаг, выполняемый блоком активностей workflow.
- `inputs` — данные, которые робот читает (файлы, аргументы, настройки).
- `outputs` — артефакты, которые робот создаёт (файлы, отчёты, значения).
- Сохраняй порядок шагов, в котором они идут от точки входа.
