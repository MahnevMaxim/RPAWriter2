# Правила разбора робота MWF (Windows Workflow Foundation)

- Точка входа робота — файл workflow, обычно `Main.xaml` (или `main.xaml`). Начинай анализ с него.
- Проследуй по всем файлам, которые вызывает workflow: целевые классы `InvokeMethod`, вложенные активности и C#-хелперы, на которые ссылается XAML.
- Распознавай только стандартные активности Windows Workflow Foundation:
  - управляющие: `Sequence`, `If`, `While`, `ForEach`;
  - передача данных: `Assign` (присваивание переменным/аргументам);
  - вызов кода: `InvokeMethod` (вызов метода C#-класса);
  - прочие: `WriteLine`, `Delay`.
- Извлекай переменные и аргументы, объявленные в XAML (`Variable`, `Argument`).
- Каждый блок активности сопоставляй с одним атомарным действием; последовательность связанных активностей образует один шаг.
- При восстановлении бизнес-логики игнорируй XML-пространства имён, `x:Class` и отображаемые имена (`DisplayName`).
