# Правила формирования задач

## 1. Задачи, касающиеся SAP

Если задача касается SAP, то работа с одной транзакцией всегда подразделяется как минимум на **2 подзадачи**:

1. **Настройка и запуск транзакции** — действия по подготовке и запуску транзакции в SAP (вход, ввод параметров, настройка, выполнение).
2. **Работа с самой транзакцией** — все действия непосредственно внутри запущенной транзакции (обработка данных, навигация по экранам, ввод/чтение информации, закрытие).

Помимо этих двух обязательных подзадач, при необходимости добавляются и другие, например:

- **Обработка данных** — преобразование, валидация, агрегация или иная обработка полученных из транзакции данных.
- **Выгрузка / сохранение результатов** — экспорт данных в файлы (Excel, CSV и т.п.) или системы.
- **Интеграции / передача данных** — отправка результатов в другие системы или сервисы.
- **Сверки** — сопоставление данных из SAP с данными из других источников (файлов, систем, отчётов) и анализ расхождений.
- **Прочее** — любые дополнительные подзадачи, требуемые логикой процесса (уведомления, логирование, обработка ошибок и т.д.).

> Таким образом, каждая SAP-транзакция в рамках одной задачи разбивается минимум на две подзадачи (настройка/запуск + работа с транзакцией), а при необходимости — и на большее количество с учётом обработки данных и прочих шагов.
