# 6. Вкладка Packages

Вкладка **Packages** предназначена для управления пакетами (например, пакетами Activity) в текущем решении.

## Кнопки

| Кнопка | Что происходит при нажатии |
|---|---|
| **Refresh** | Перечитывает список доступных пакетов из источника пакетов |
| **Install selected** | Устанавливает выбранные (отмеченные галочкой) пакеты |
| **Update selected** | Обновляет выбранные пакеты до выбранных версий |
| **Uninstall selected** | Удаляет выбранные пакеты |
| **Restore packages** | Выполняет `Update-Package -Reinstall` для текущего решения (кнопка в нижней панели) |

## Фильтр

Поле **Filter:** (по умолчанию `Activities.`) показывает только пакеты, имя которых начинается с введённого значения. Фильтр применяется по мере ввода текста.

## Список пакетов

Каждая строка списка содержит:

- **флажок** — выбор пакета для установки/обновления/удаления;
- **Id** — идентификатор пакета (жирным);
- **выпадающий список версий** — выбор конкретной версии;
- **Installed** — зелёный бейдж, если пакет уже установлен;
- **описание** — краткое описание пакета.

Под списком — строка состояния (**PackagesStatusText**).

## Нижняя панель восстановления

Панель **Restore packages** появляется, когда уместно восстановить пакеты. Содержит кнопку **Restore packages** и пояснение `Update-Package -Reinstall for the current solution`.
