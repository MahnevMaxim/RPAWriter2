# 17. MCP-серверы

Расширение умеет подключаться к внешним **MCP-серверам** (Model Context Protocol) и отдавать их
инструменты агенту в чате. Это позволяет расширять возможности агента сторонними инструментами
(браузер, базы данных, поиск и т.п.), не встраивая их в расширение.

## Включение

1. Во вкладке **Chat** откройте **Permissions** и включите право **MCP**.
2. Во вкладке **Settings → API** вставьте JSON-блок `mcpServers` в поле **MCP servers (JSON)**.
3. Нажмите **Save settings**.

> Право **MCP** обязательно: без него инструменты MCP не показываются модели и не исполняются.

## Формат конфигурации

Формат совместим с конфигурацией Cline/Roo — существующий блок `mcpServers` можно вставить без
изменений. Допускается как обёртка `{ "mcpServers": { ... } }`, так и голый объект `{ "name": { ... } }`.

```json
{
  "mcpServers": {
    "playwright": {
      "command": "npx",
      "args": ["@playwright/mcp@latest"]
    },
    "my-http-server": {
      "url": "https://example.com/mcp",
      "type": "http",
      "timeout": 30
    }
  }
}
```

Поля одного сервера:

| Поле | Назначение |
|---|---|
| `command` | Исполняемый файл для запуска (stdio): `npx`, `uvx`, `node`, … |
| `args` | Аргументы командной строки |
| `env` | Дополнительные переменные окружения |
| `url` | URL сервера для HTTP-транспортов |
| `type` | Тип транспорта: `stdio` / `http` (`streamablehttp`) / `sse` |
| `disabled` | `true` — пропустить сервер без запуска |
| `timeout` | Таймаут handshake/запроса в секундах (по умолчанию `30`) |

## Транспорты

| Транспорт | Когда используется | Описание |
|---|---|---|
| **stdio** | задан `command` (или нет `url`) | Расширение запускает сервер как подпроцесс и общается через stdin/stdout |
| **streamable HTTP** | задан `url` (по умолчанию) | Сервер работает как HTTP-сервис по URL |
| **SSE** | `type: "sse"` | Устаревший вариант HTTP + Server-Sent Events (для совместимости) |

Если указан `url` без явного `type`, подразумевается HTTP-транспорт.

## Какие инструменты получает агент

Для каждого подключённого сервера агент получает:

- все инструменты, объявленные сервером (адаптируются как обычные агент-инструменты с префиксом
  `mcp__<server>__...`);
- read-only инструменты контекста: `list_resources`, `read_resource`, `list_prompts`, `get_prompt`
  (доступны и в Plan-режиме, поскольку не меняют состояние).

## Устойчивость к ошибкам

Сбой одного сервера не ломает остальных: ошибки запуска собираются отдельно по каждому серверу и
выводятся как уведомление, а исправные серверы продолжают работать.

## Реестр серверов

Кнопка **Browse MCP Registry** (рядом с полем конфигурации) открывает официальный реестр MCP-серверов
в браузере, чтобы найти готовые серверы и их команды запуска.
