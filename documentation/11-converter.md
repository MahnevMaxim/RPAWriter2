# 11. Окно инструментов Converter

Окно инструментов **Converter** (View → Other Windows → RPA Writer Converter) — универсальный конвертер роботов в Windows Workflow Foundation (WF/MWF): перенос роботов **UiPath** и **PIX** в обычный XAML + C#, импорт библиотек активностей и ручной/AI-маппинг активностей PIX на WF.

## Кнопки

| Кнопка | Что происходит при нажатии |
|---|---|
| **UiPath → MWF** | Открывает диалог выбора XAML UiPath и конвертирует его в Workflow Foundation: рядом с исходным файлом создаются `.wf.xaml` и `.wf.cs`. |
| **Convert PIX to MWF** | Открывает панель конвертации папки робота PIX: поля **PIX robot folder** и **MWF target folder** + кнопка **Start conversion**. Конвертирует все задействованные скрипты робота (см. ниже). |
| **Parse All Activities From PIX** | Парсит `.pix`-файлы (XAML) в выбранной папке роботов PIX, подсчитывает использованные активности и предупреждает о тех, которых нет в библиотеке конвертера. Пишет отчёт `PixMissingActivities.md` и открывает таблицу маппинга, отфильтрованную по найденным активностям. |
| **Import PIX activities (rewrite library)** | Пересобирает библиотеку активностей PIX: рефлексией по установленным сборкам PIX (`Core.dll` + `Activities.*.dll`) создаёт JSON-дескрипторы в `ActivityLibrary/pix`. |
| **Get All MWF Activities** | Импортирует WF-активности из C#-исходников выбранной папки (если они есть) в библиотеку `ActivityLibrary/mwf`, а встроенные активности из `System.Activities.dll` — только выбранные в фильтре **Select System Activities**. Сборки `Activities.*.dll` не сканируются. |
| **View WF snippets** | Открывает окно **WF Snippets** — просмотр XAML-сниппетов WF из `ActivityLibrary/wf` (шаблоны с плейсхолдерами `{{…}}`). |
| **Get System Activities** | Рефлексией по `System.Activities.dll` собирает список встроенных активностей WF и сохраняет его (вместе с выбором) в `%AppData%\RPAWriter2\<17|18>\system-activities.json`. |
| **Select System Activities** | Открывает список собранных системных активностей с чекбоксами — отметить, какие активности `System.Activities` должны импортироваться кнопкой **Get All MWF Activities**. |
| **PIX to MWF map** | Открывает таблицу маппинга активностей PIX на активности WF (см. ниже). |
| **Clear** | Очищает область вывода конвертера. |

## Конвертация UiPath → WF (UiPath → MWF)

1. Открывается диалог выбора XAML UiPath.
2. Файл читается, строится план робота (`RobotPlan`).
3. Стандартные активности (Sequence, If, While, ForEach, Assign, Delay, WriteLine) переносятся в соответствующие узлы WF.
4. UiPath-специфичные активности (OpenBrowser, TypeInto, Click, ReadRange, WriteRange, LogMessage и др.) сопоставляются с вызовами C#-методов класса `RpaActions` через `InvokeMethod`.
5. Рядом с исходным файлом создаются `<имя>.wf.xaml` и `<имя>.wf.cs`; в выводе указывается число предупреждений.

## Конвертация PIX → MWF (Convert PIX to MWF)

1. Нажмите **Convert PIX to MWF** — раскроется панель конвертации с полями **PIX robot folder** и **MWF target folder** (и кнопкой **Close**).
   - поле **PIX robot folder** при первом открытии предзаполняется из настройки **Robot solutions directory**;
   - поле **MWF target folder** — каталогом открытого решения;
   - введённые папки сохраняются между сессиями (`%AppData%\RPAWriter2\<17|18>\pix-robot-conversion.json`).
2. Задайте папку робота PIX и целевую папку MWF (кнопки **Browse…**).
3. Нажмите **Start conversion**.
4. Определяется набор «задействованных скриптов»:
   - если в папке есть `.pixproj`, берётся список файлов из `<Files>` (файл с `IsMain=true` — точка входа);
   - иначе стартуем с `main.pix` и рекурсивно следуем по ссылкам `BR.Core.Base.ExecuteScript` (свойство `FilePath`).
5. Каждый скрипт конвертируется через библиотеку готовых XAML-сниппетов `ActivityLibrary/wf` (активности вставляются в XAML программно с подстановкой плейсхолдеров и XML-экранированием значений) с применением текущего маппинга PIX→MWF из таблицы **PIX to MWF map**.
6. Если у активности нет ни маппинга, ни встроенного сниппета WF — конвертация прерывается с сообщением об ошибке (нужно назначить соответствие в таблице **PIX to MWF map**).
7. В папку MWF пишутся: `Main.xaml` (из `main.pix`), `<Имя>.xaml` для остальных скриптов, агрегированный `RpaActions.cs` (методы всех скриптов) и отчёт `conversion-report.txt`.
8. Вызов скрипта `ExecuteScript` превращается в ссылку на сгенерированный workflow `<local:<КлассСкрипта> …/>`; если `FilePath` не удаётся разрешить статически — выдаётся предупреждение и остаётся заглушка `RpaActions.ExecuteScript`.

## Парсинг активностей PIX (Parse All Activities From PIX)

1. Открывается диалог выбора папки с роботами PIX.
2. Все `.pix`-файлы парсятся, подсчитывается число вхождений каждой активности.
3. Активности, отсутствующие в библиотеке конвертера, показываются как предупреждение и попадают в отчёт `PixMissingActivities.md` (папка `temp/` решения или исходной папки) с «рейтингом» — общим числом вхождений.
4. Найденные активности используются как фильтр: открывается таблица **PIX to MWF map**, отфильтрованная только по этим активностям — маппинг создаётся именно по ним.

## Импорт библиотек активностей

- **Import PIX activities (rewrite library)** — определяет каталог установки PIX (`Program Files\PIX` или `Program Files (x86)\PIX`; если не найден — запрашивает вручную), рефлексией по `Core.dll` и `Activities.*.dll` извлекает конкретные активности `BR.Core.Activity` и перезаписывает JSON-дескрипторы в `ActivityLibrary/pix` (при открытом решении также обновляется исходная библиотека решения).
- **Get System Activities** — рефлексией по встроенной `System.Activities.dll` собирает стандартные активности Workflow Foundation (названия и описания) и сохраняет список в `%AppData%\RPAWriter2\<17|18>\system-activities.json`. При первом сборе выбираются все активности.
- **Select System Activities** — открывает окно со списком собранных системных активностей, где можно отметить (чекбоксами), какие из них импортировать; выбор сохраняется в тот же файл.
- **Get All MWF Activities** — запрашивает папку с WF-активностями. Если в папке есть C#-исходники (`*.cs`), парсит их. Активности `System.Activities` добавляются только из фильтра, настроенного в **Select System Activities** (если список ещё не собирался — добавляются все). Сборки `Activities.*.dll` не сканируются. Перезаписывает JSON-дескрипторы в `ActivityLibrary/mwf`.

Во всех случаях в вывод выводится сводка: число просканированных сборок, импортированных активностей, записанных и удалённых (устаревших) файлов-дескрипторов, а также ошибки.

## Просмотр WF-сниппетов (View WF snippets)

Кнопка **View WF snippets** открывает модальное окно **WF Snippets**: слева — список сниппетов WF из каталога `ActivityLibrary/wf`, справа — XAML-шаблон выбранного сниппета (с маркерами `{{…}}`). Эти же сниппеты конвертер **Convert PIX to MWF** использует для программной вставки активностей.

## Маппинг PIX → MWF (PIX to MWF map)

Таблица сопоставления активностей PIX активностям Workflow Foundation. Открывается кнопкой **PIX to MWF map** и содержит колонки:

| Колонка | Назначение |
|---|---|
| **PIX Activity** | Полное имя активности PIX |
| **PIX Name** | Отображаемое имя активности PIX |
| **MWF Activity** | Выпадающий список доступных WF-активностей для сопоставления |
| **MWF Description** | Описание выбранной WF-активности |
| **…** | Кнопка **Assign** (назначить) / **Unmap** (снять сопоставление) |

В каждой строке кнопка **Args** раскрывает панель с аргументами PIX и MWF. Для сопоставленной активности в этой панели появляется кнопка **Map arguments**, которая переключает панель в редактор сопоставления аргументов:

- слева — аргумент PIX (имя, тип, направление, описание);
- справа — выпадающий список аргументов MWF выбранной активности и приведение типа (**None / ToString / Parse / DateTime / Custom** с выражением или форматом, где `{0}` — исходное значение);
- кнопка **Auto-match** подставляет соответствия по имени, затем по типу.

Карта аргументов сохраняется вместе с картой активностей и применяется конвертером **Convert PIX to MWF** (подстановка имени аргумента и заданного приведения). Полные описания активностей и всех их аргументов PIX/MWF получаются импортёрами библиотек; AI-маппинг аргументов запускается кнопкой **AI Map arguments** (или через нативные инструменты `list_pix_mwf_activities` и `map_pix_mwf_arguments` в чате в режиме Act).

Кнопки панели:

| Кнопка | Что делает |
|---|---|
| **AI Map** | Отправляет список активностей AI-провайдеру, который назначает сопоставления через инструмент `map_pix_to_mwf` |
| **AI Map arguments** | Для сопоставленных активностей отправляет их аргументы (PIX и MWF с полными описаниями) AI-провайдеру, который назначает сопоставления аргументов через инструмент `map_pix_mwf_arguments` |
| **Save** | Сохраняет текущий маппинг в файл по умолчанию |
| **Save As…** | Сохраняет текущий маппинг в файл с выбранным именем |
| **Reload** | Перечитывает активности PIX/WF и сохранённый маппинг |
| **Cancel** | Отменяет выполняющийся AI-маппинг |
| **Close** | Закрывает таблицу |

Поля фильтров: **PIX activities filter** фильтрует строки таблицы по полному или отображаемому имени активности PIX (по мере ввода); **MWF activities filter** (ниже) фильтрует выпадающий список в колонке **MWF Activity** по полному/отображаемому имени или описанию активности WF. Кнопки **Clear filter** сбрасывают соответствующий фильтр. После парсинга папки (**Parse All Activities From PIX**) таблица автоматически открывается с фильтром «только найденные активности».

Маппинг (активности и аргументы) хранится в `%AppData%\RPAWriter2\<17|18>\pix-mwf-map.json` и используется конвертером **Convert PIX to MWF**.

### Типичный сценарий

1. Нажмите **Import PIX activities (rewrite library)** и **Get All MWF Activities**, чтобы наполнить библиотеки.
2. Нажмите **PIX to MWF map** и назначьте соответствия вручную или кнопкой **AI Map**.
3. Нажмите **Save**.
4. Нажмите **Convert PIX to MWF** — конвертер применит сохранённый маппинг.

## Область вывода

Под кнопками находится прокручиваемая область вывода, куда попадают результат конвертации (XAML и C#), сводки импорта библиотек и сообщения о созданных файлах. Кнопка **Copy all** (иконка) копирует весь вывод в буфер обмена.
