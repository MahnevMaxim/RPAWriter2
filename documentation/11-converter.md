# 11. Вкладка Converter

Вкладка **Converter** — универсальный конвертер роботов в Windows Workflow Foundation (WF/MWF): перенос роботов **UiPath** и **PIX** в обычный XAML + C#, импорт библиотек активностей и ручной/AI-маппинг активностей PIX на WF.

## Кнопки

| Кнопка | Что происходит при нажатии |
|---|---|
| **UiPath → MWF** | Открывает диалог выбора XAML UiPath и конвертирует его в Workflow Foundation: рядом с исходным файлом создаются `.wf.xaml` и `.wf.cs`. |
| **Convert PIX to MWF** | Открывает диалог выбора робота PIX (`.pix`) и конвертирует его в WF с учётом текущего маппинга PIX→MWF (см. ниже). Создаются `.wf.xaml`, `.wf.cs` и отчёт `.wf.txt`. |
| **Get All Activities From PIX Folder** | Сканирует папку с `.pix`-роботами, подсчитывает использованные активности и находит те, которых нет в библиотеке конвертера. Пишет отчёт `PixMissingActivities.md`. |
| **Import PIX activities (rewrite library)** | Пересобирает библиотеку активностей PIX: рефлексией по установленным сборкам PIX (`Core.dll` + `Activities.*.dll`) создаёт JSON-дескрипторы в `ActivityLibrary/pix`. |
| **Get All MWF Activities** | Импортирует WF-активности из выбранной папки (сборки `Activities.*.dll`) и встроенные активности из `System.Activities.dll` в библиотеку `ActivityLibrary/mwf`. |
| **PIX to MWF map** | Открывает таблицу маппинга активностей PIX на активности WF (см. ниже). |
| **Clear** | Очищает область вывода конвертера. |

## Конвертация UiPath → WF (UiPath → MWF)

1. Открывается диалог выбора XAML UiPath.
2. Файл читается, строится план робота (`RobotPlan`).
3. Стандартные активности (Sequence, If, While, ForEach, Assign, Delay, WriteLine) переносятся в соответствующие узлы WF.
4. UiPath-специфичные активности (OpenBrowser, TypeInto, Click, ReadRange, WriteRange, LogMessage и др.) сопоставляются с вызовами C#-методов класса `RpaActions` через `InvokeMethod`.
5. Рядом с исходным файлом создаются `<имя>.wf.xaml` и `<имя>.wf.cs`; в выводе указывается число предупреждений.

## Конвертация PIX → WF (Convert PIX to MWF)

1. Открывается диалог выбора `.pix`.
2. Файл читается, строится план робота по библиотеке активностей PIX; применяется текущий маппинг PIX→MWF из таблицы **PIX to MWF map**.
3. Создаются `<имя>.wf.xaml` и `<имя>.wf.cs`, а также текстовый отчёт `<имя>.wf.txt` (источник, пути выходных файлов, предупреждения, применённые маппинги).
4. Если открыто решение — файлы пишутся в `temp/` решения; иначе — рядом с исходным файлом.

## Сканирование активностей PIX (Get All Activities From PIX Folder)

1. Открывается диалог выбора папки с роботами PIX.
2. Все `.pix`-файлы сканируются, подсчитывается число вхождений каждой активности.
3. Активности, отсутствующие в библиотеке конвертера, попадают в отчёт `PixMissingActivities.md` (папка `temp/` решения или исходной папки) с «рейтингом» — общим числом вхождений.
4. Все найденные активности дописываются в библиотеку конвертера (если их там ещё нет) и открывается таблица **PIX to MWF map**, отфильтрованная только по этим активностям — маппинг создаётся именно по ним.

## Импорт библиотек активностей

- **Import PIX activities (rewrite library)** — определяет каталог установки PIX (`Program Files\PIX` или `Program Files (x86)\PIX`; если не найден — запрашивает вручную), рефлексией по `Core.dll` и `Activities.*.dll` извлекает конкретные активности `BR.Core.Activity` и перезаписывает JSON-дескрипторы в `ActivityLibrary/pix` (при открытом решении также обновляется исходная библиотека решения).
- **Get All MWF Activities** — запрашивает папку с WF-активностями, рефлексией по `Activities.*.dll` и встроенной `System.Activities.dll` извлекает активности, наследующие `System.Activities.Activity`, и перезаписывает JSON-дескрипторы в `ActivityLibrary/mwf`.

В обоих случаях в вывод выводится сводка: число просканированных сборок, импортированных активностей, записанных и удалённых (устаревших) файлов-дескрипторов, а также ошибки.

## Маппинг PIX → MWF (PIX to MWF map)

Таблица сопоставления активностей PIX активностям Workflow Foundation. Открывается кнопкой **PIX to MWF map** и содержит колонки:

| Колонка | Назначение |
|---|---|
| **PIX Activity** | Полное имя активности PIX |
| **PIX Name** | Отображаемое имя активности PIX |
| **MWF Activity** | Выпадающий список доступных WF-активностей для сопоставления |
| **MWF Description** | Описание выбранной WF-активности |
| **…** | Кнопка **Assign** (назначить) / **Unmap** (снять сопоставление) |

В каждой строке кнопка **Args** раскрывает панель с аргументами PIX и MWF. Для сопоставленной активности в этой панели появляется кнопка **Map arguments**, которая переключает панель в редактор сопоставления аргументов:

- слева — аргумент PIX (имя, тип, направление, описание);
- справа — выпадающий список аргументов MWF выбранной активности и приведение типа (**None / ToString / Parse / DateTime / Custom** с выражением или форматом, где `{0}` — исходное значение);
- кнопка **Auto-match** подставляет соответствия по имени, затем по типу.

Карта аргументов сохраняется вместе с картой активностей и применяется конвертером **Convert PIX to MWF** (подстановка имени аргумента и заданного приведения). Полные описания активностей и всех их аргументов PIX/MWF получаются импортёрами библиотек; AI-маппинг аргументов запускается кнопкой **AI Map arguments** (или через нативные инструменты `list_pix_mwf_activities` и `map_pix_mwf_arguments` в чате в режиме Act).

Кнопки панели:

| Кнопка | Что делает |
|---|---|
| **AI Map** | Отправляет список активностей AI-провайдеру, который назначает сопоставления через инструмент `map_pix_to_mwf` |
| **AI Map arguments** | Для сопоставленных активностей отправляет их аргументы (PIX и MWF с полными описаниями) AI-провайдеру, который назначает сопоставления аргументов через инструмент `map_pix_mwf_arguments` |
| **Save** | Сохраняет текущий маппинг в файл по умолчанию |
| **Save As…** | Сохраняет текущий маппинг в файл с выбранным именем |
| **Reload** | Перечитывает активности PIX/WF и сохранённый маппинг |
| **Cancel** | Отменяет выполняющийся AI-маппинг |
| **Close** | Закрывает таблицу |

Поля фильтров: **PIX activities filter** фильтрует строки таблицы по полному или отображаемому имени активности PIX (по мере ввода); **MWF activities filter** (ниже) фильтрует выпадающий список в колонке **MWF Activity** по полному/отображаемому имени или описанию активности WF. Кнопки **Clear filter** сбрасывают соответствующий фильтр. После сканирования папки (**Get All Activities From PIX Folder**) таблица автоматически открывается с фильтром «только найденные активности».

Маппинг (активности и аргументы) хранится в `%AppData%\RPAWriter2\pix-mwf-map.json` и используется конвертером **Convert PIX to MWF**.

### Типичный сценарий

1. Нажмите **Import PIX activities (rewrite library)** и **Get All MWF Activities**, чтобы наполнить библиотеки.
2. Нажмите **PIX to MWF map** и назначьте соответствия вручную или кнопкой **AI Map**.
3. Нажмите **Save**.
4. Нажмите **Convert PIX to MWF** — конвертер применит сохранённый маппинг.

## Область вывода

Под кнопками находится прокручиваемая область вывода, куда попадают результат конвертации (XAML и C#), сводки импорта библиотек и сообщения о созданных файлах. Кнопка **Copy all** (иконка) копирует весь вывод в буфер обмена.
