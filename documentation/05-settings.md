# 5. Вкладка Settings

Вкладка **Settings** содержит все настройки расширения. Настройки сохраняются локально в JSON (`%AppData%\RPAWriter2\settings.json`) по кнопке **Save settings**.

## Провайдер AI

| Поле | Назначение | По умолчанию |
|---|---|---|
| **Base URL** | Базовый URL OpenAI-совместимого API | `https://api.openai.com/v1` |
| **API key** | Ключ доступа к провайдеру (скрыт точками) | пусто |
| **Model** | Имя модели | `gpt-4o-mini` |

## Пути

| Поле | Назначение |
|---|---|
| **KB directory** | Каталог базы знаний (JSON-индекс `index.json`) |
| **Robot solutions directory** | Каталог решений/роботов |
| **Robot template file name** | Имя файла шаблона робота (для создания нового робота) |
| **Rules directory (md)** | Каталог правил платформ (по умолчанию — `Prompts/Rules` расширения) |
| **Log file path** | Путь к файлу журнала расширения (рядом кнопка **Open log**) |
| **Chat log file path** | Путь к файлу журнала чата (рядом кнопка **Open log**) |
| **Packages directory (NuGet source)** | Каталог/источник пакетов |
| **Log providers directory** | Каталог провайдеров логов |
| **Skills directory** | Каталог навыков (каждый навык — подпапка с `SKILL.md`) |
| **Vosk model directory** | Каталог модели Vosk для офлайн-распознавания речи |

## Контекстное окно

| Поле | Назначение | По умолчанию |
|---|---|---|
| **Context window (tokens)** | Размер контекстного окна модели | `409600` |
| **Compact threshold (0..1)** | Порог заполнения, после которого запускается авто-сжатие | `0.85` |
| **Reserve fraction (0..1)** | Доля окна, резервируемая под ответ модели | `0.12` |
| **Keep recent messages** | Сколько последних сообщений не сжимаются | `6` |
| **Tool result max chars** | Максимум символов результата инструмента, возвращаемого в беседу | `12000` |
| **Auto-compact (summarize)** | Автоматически суммировать беседу при приближении к лимиту | вкл. |

> 📘 Как работает контекстное окно, автосжатие, восстановление при переполнении и Memory Bank — см. [Управление контекстом и память](10-context.md).

## Агент

| Поле | Назначение | По умолчанию |
|---|---|---|
| **Max agent iterations** | Максимум итераций агентного цикла за один запуск | `8` |
| **Tool calling** | Протокол вызова инструментов: **JSON over chat** или **Native function calling** | JsonChat |
| **Memory bank** | Режим банка памяти: **Disabled** / **Tool** / **Convention** | Disabled |
| **Use 'tool' role for tool results** | Использовать роль `tool` для результатов инструментов (иначе `user`) | вкл. |
| **User name** | Имя пользователя (для обращения по имени) | пусто |
| **Address me by name** | Агент обращается к вам по имени | выкл. |
| **Enable sub-agents (spawn_agent)** | Разрешить запуск субагентов | выкл. |
| **Sub-agent max iterations** | Максимум итераций субагента | `4` |
| **Sub-agent max depth** | Максимальная глубина вложенности субагентов (1–5) | `2` |
| **Show controls** | Показывать скрытую вкладку **Controls** | выкл. |

## Сеть и повторы

| Поле | Назначение | По умолчанию |
|---|---|---|
| **Request timeout (s)** | Таймаут HTTP-запроса к провайдеру (сек) | `300` |
| **Retry budget (min)** | Общий бюджет времени на повторы сбойного запроса (мин) | `30` |
| **Retry base delay (s)** | Начальная задержка между повторами (удваивается) | `1` |
| **Retry max delay (s)** | Максимальная задержка между повторами | `30` |

## Стоимость (для оценки расходов)

| Поле | Назначение | По умолчанию |
|---|---|---|
| **Input price ($/1M tokens)** | Цена за 1M входных (некэшированных) токенов | `0.27` |
| **Cache-hit price ($/1M tokens)** | Цена за 1M кэшированных входных токенов | `0.07` |
| **Output price ($/1M tokens)** | Цена за 1M выходных токенов | `1.10` |

Стоимость оценивается по этим ценам и показывается в индикаторе контекста (вместе с cache-hit токенами).

## Голосовой ввод

| Поле | Назначение | По умолчанию |
|---|---|---|
| **Speech recognition** | Провайдер распознавания: **Auto (Whisper, fallback Vosk)** / **OpenAI Whisper** / **Vosk (offline)** | Auto |
| **Whisper STT model** | Модель Whisper | `whisper-1` |
| **Speech language** | Язык распознавания | `ru` |
| **Auto-send voice input** | Автоматически отправлять распознанный текст (если поле пустое) | выкл. |

## Аудит безопасности

| Поле | Назначение | По умолчанию |
|---|---|---|
| **Security audit mode** | Режим аудита робота: **Full (all areas)** — полный статический анализ по всем категориям, или **Passwords & logins only** — только поиск захардкоженных паролей и логинов (подозрительные конфиги + data-flow строковых значений) | Full |

## Кнопки

| Кнопка | Что делает |
|---|---|
| **Save settings** | Сохраняет все настройки в JSON и применяет их |
| **Refresh prompts from disk** | Перечитывает файлы промптов из каталога `Prompts` расширения |

> 💡 После изменения настроек провайдера или промптов обычно не нужно перезапускать Visual Studio — изменения применяются после сохранения.
