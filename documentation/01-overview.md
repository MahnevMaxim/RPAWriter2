# 1. Общее назначение

## Что такое RPA Writer

**RPA Writer** — это VSIX-расширение Visual Studio, реализующее AI-агента для разработки RPA-роботов на **Windows Workflow Foundation (WF)**.

Обычный цикл разработки RPA-робота выглядит так:

1. Вручную читается техническое задание (ТЗ).
2. ТЗ вручную раскладывается на отдельные задачи.
3. По каждой задаче вручную пишется workflow (XAML) и вспомогательный код (C#).
4. Похожие решения ищутся заново между проектами.

RPA Writer автоматизирует этот цикл:

- читает ТЗ из Word/Excel/текста;
- декомпозирует ТЗ на атомарные задачи с помощью AI;
- генерирует XAML и C#-хелперы робота;
- ведёт локальную базу знаний и ищет похожие решения;
- конвертирует роботов UiPath в обычный Workflow Foundation;
- собирает проект, читает ошибки компиляции, окно вывода и логи.

## Как установить

1. Соберите или получите `.vsix`-пакет расширения.
2. Дважды щёлкните по `.vsix` или установите через `Extensions → Manage Extensions`.
3. Перезапустите Visual Studio.

## Как открыть окно

- Меню: **View → Other Windows → RPA Writer**;
- либо команда в меню расширения (**Tools → RPA Writer**).

Окно открывается как панель инструментов (tool window) и может быть закреплено в любом месте IDE.

## Первый запуск

1. Откройте вкладку **Settings**.
2. Заполните **Base URL**, **API key** и **Model** вашего AI-провайдера.
3. При необходимости задайте **KB directory** (каталог базы знаний) и **Robot solutions directory** (каталог решений роботов).
4. Нажмите **Save settings**.

После этого можно перейти в **Chat** и начать работу.

## Ключевые понятия

| Термин | Значение |
|---|---|
| **Спецификация (Spec)** | Нормализованное ТЗ: название, шаги, входы/выходы, список задач |
| **Задача (Task)** | Атомарное действие: `действие → цель [тип активности]` |
| **База знаний (KB)** | Локальный каталог с JSON-индексом переиспользуемых решений |
| **Робот** | Workflow Foundation проект: XAML-файл workflow + C#-хелперы |
| **Режим Plan** | Агент только читает и анализирует; изменения запрещены |
| **Режим Act** | Агент может изменять файлы, создавать роботов, запускать сборки |
| **Режим Help** | Агент поддержки, отвечающий по встроенной документации |

## AI-провайдер

Расширение работает с любым **OpenAI-совместимым** провайдером (`POST /chat/completions`):

- OpenAI;
- Azure OpenAI;
- Ollama (локально);
- LM Studio (локально);
- vLLM;
- DeepSeek и другие.

При отсутствии провайдера предусмотрен офлайн-заглушка (`StubAiProvider`) для тестирования интерфейса.

## Сценарии использования

1. **Разработка по ТЗ** — импортируйте ТЗ на вкладке Spec и нажмите **Generate robot** (или попросите агента в Chat сгенерировать робота).
2. **Переиспользование** — найдите похожие задачи в базе знаний и адаптируйте готовые решения.
3. **Миграция с UiPath** — конвертируйте XAML UiPath в Workflow Foundation одной кнопкой.
4. **Диагностика** — отправьте ошибки компиляции или логи в чат и попросите агента проанализировать их.
