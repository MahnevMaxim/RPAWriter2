# 4. Вкладка Knowledge base

Вкладка **Knowledge base** служит для формирования локальной базы знаний из существующих роботов: документация роботов разбивается на мелкие задачи, и для каждой задачи находится решение в коде робота.

## Элементы управления

| Элемент | Что делает |
|---|---|
| **Override (start over)** / **Continue (resume)** | Режим импорта: начать базу заново или продолжить с места остановки |
| **Import from robots** | Запускает формирование базы знаний из каталога роботов |
| **Pause** | Приостанавливает импорт (становится активной во время импорта) |
| **Stop** | Останавливает импорт |
| **Refresh** | Перечитывает и обновляет список решений в базе знаний |

## Область состояния

- **Статус** — многострочное поле с текущим статусом импорта.
- **Прогресс-бар** — процент выполнения импорта (виден во время работы).
- **Context window** — полоса заполнения и текст `Context window: N` (оценка использования контекстного окна).

## Журнал сообщений

- Поле **Messages:** — журнал хода импорта.
- Флажок **Auto-scroll** — автоматическая прокрутка журнала вниз при появлении новых строк.

## Как формируется база знаний

1. Выбирается режим: **Override** (заново) или **Continue** (продолжить).
2. Нажимается **Import from robots** — запускается `KnowledgeBaseFormationService`.
3. Для каждого робота в каталоге:
   - читается документация робота;
   - документация разбивается на мелкие задачи;
   - в коде робота находится решение для каждой задачи;
   - задачи и решения сохраняются в индекс базы знаний (`index.json`).
4. Прогресс и сообщения отображаются в журнале; импорт можно приостановить или остановить.

## Где хранится база

База знаний — это локальный каталог, задаваемый настройкой **KB directory** (вкладка Settings), с JSON-индексом `index.json`. Отдельная СУБД или векторное хранилище не используются.

Поиск похожих задач выполняется токенным сходством (Jaccard) с бустами за тип активности/действие.
