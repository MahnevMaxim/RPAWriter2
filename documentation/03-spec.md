# 3. Вкладка Spec

Вкладка **Spec** предназначена для работы со спецификацией (техническим заданием): импорт, декомпозиция на задачи, поиск похожих решений и конвертация роботов UiPath.

## Кнопки

| Кнопка | Что происходит при нажатии |
|---|---|
| **Import spec** | Открывает диалог выбора ТЗ (`.docx`, `.doc`, `.xlsx`, `.xls`, `.txt`, `.md`), читает его, декомпозирует на задачи (через AI) и сохраняет структурированные `spec.md` и `tasks.md` в папку `docs` решения. |
| **Find similar** | Ищет в базе знаний задачи, похожие на текущую спецификацию. |
| **UiPath → WF** | Открывает диалог выбора XAML-файла UiPath и конвертирует его в Workflow Foundation: рядом создаются `.wf.xaml` и `.wf.cs`. |
| **Copy all** (иконка) | Копирует весь вывод спецификации в буфер обмена (появляется, когда есть вывод). |

## Импорт ТЗ (Import spec) — пошагово

1. Проверяется, что открыто решение (иначе — предупреждение).
2. Открывается диалог выбора файла.
3. Проверяется, не заблокирован ли файл другим приложением (Word/Excel).
4. Файл читается (`OpenXmlDocumentReader` для `.docx`/`.xlsx`, NPOI для legacy `.doc`/`.xls`, текст для `.txt`/`.md`).
5. Создаётся/обновляется `docs/spec.md` (структурированный markdown).
6. AI декомпозирует ТЗ на задачи, создаётся `docs/tasks.md`.
7. Спецификация и список задач отображаются в области вывода.

Если `spec.md`/`tasks.md` уже существуют, появится диалог: перезаписать полностью, найти расхождения и предложить частичное исправление, либо оставить без изменений.

## Конвертация UiPath → WF — пошагово

1. Открывается диалог выбора XAML UiPath.
2. Файл читается, строится `RobotPlan`.
3. Стандартные активности (Sequence, If, While, ForEach, Assign, Delay, WriteLine) переносятся в соответствующие узлы WF.
4. UiPath-специфичные активности (OpenBrowser, TypeInto, Click, ReadRange, WriteRange, LogMessage и др.) сопоставляются с вызовами C#-методов класса `RpaActions` через `InvokeMethod`.
5. Результат сохраняется в `.wf.xaml` и `.wf.cs` рядом с исходным файлом; в выводе указывается число предупреждений.

## Область вывода

Под кнопками находится прокручиваемая область вывода, куда попадают:

- текст импортированной спецификации и список задач;
- результаты конвертации UiPath;
- сообщения о созданных/перезаписанных файлах.

## Заметки

- Импорт доступен только при открытом решении (файлы `docs/spec.md` и `docs/tasks.md` создаются в папке решения).
- Если файл ТЗ открыт в Word/Excel, импорт будет остановлен с сообщением «файл заблокирован».
