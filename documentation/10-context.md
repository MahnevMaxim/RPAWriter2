# 10. Управление контекстом и память

RPA Writer автоматически следит за заполнением контекстного окна модели и хранит долговременную память проекта в **Memory Bank**. Эта страница объясняет, как это работает, и перечисляет связанные настройки.

## Контекстное окно

Модель имеет ограниченное контекстное окно (настраивается в Settings → **Context window (tokens)**). В это окно попадают системный промпт, вся история беседы и результаты инструментов.

### Индикатор заполнения

Во вкладке **Chat** над списком сообщений отображается:

- полоса **Context window** — визуальная индикация заполнения окна;
- текст **Context window: N / M** — оценка использованных токенов `N` от размера окна `M`.

### Оценка токенов

Расширение оценивает токены консервативно, без обращения к токенизатору провайдера: примерно `⌈символы / 4⌉` плюс небольшая накладная величина на каждое сообщение (`TokenEstimator`).

## Автосжатие (auto-compact)

Когда оценка входного контекста приближается к лимиту, запускается автоматическое сжатие истории. Пороги задаются настройками:

- **Compact threshold (0..1)** — доля окна, при которой запускается сжатие (по умолчанию `0.85`);
- **Reserve fraction (0..1)** — доля окна, резервируемая под ответ модели (по умолчанию `0.12`);
- **Keep recent messages** — сколько последних сообщений не сжимается (по умолчанию `6`).

Сжатие (`ContextCondenser`) работает так:

1. Последние `Keep recent messages` сообщений сохраняются без изменений.
2. Более старые сообщения **суммируются той же моделью** и заменяются коротким блоком «Summary of the earlier conversation».
3. Если суммаризация недоступна или не удалась — выполняется **fallback-усечение**: старые сообщения отбрасываются, пока контекст не уложится в бюджет.

Включить/выключить автосжатие можно настройкой **Auto-compact (summarize)**. Принудительно сжать историю вручную — кнопка **Compact now** внизу вкладки Chat.

## Восстановление при переполнении

Если модель всё же отвечает ошибкой переполнения, агент восстанавливается автоматически:

- **overflow recovery** — при `context_window_exceeded` контекст сжимается, и запрос повторяется;
- **max-tokens recovery** — при `finish_reason == "length"` (ответ обрезан) агенту отправляется «nudge» с просьбой продолжить, и запрос повторяется.

## Токены и стоимость

Провайдер возвращает сведения об использовании токенов; расширение их накапливает и показывает в индикаторе контекста:

- **Prompt / Completion / Total tokens** — обычные токены;
- **Cache-hit / Cache-miss tokens** — входные токены, поданные из кэша промпта и вне его. Поддерживаются форматы DeepSeek (`prompt_cache_hit_tokens` / `prompt_cache_miss_tokens`) и OpenAI (`prompt_tokens_details.cached_tokens`);
- **Estimated cost ($)** — оценка стоимости по настраиваемым ценам за 1M токенов (**Input price**, **Cache-hit price**, **Output price** в Settings).

## Memory Bank

Memory Bank — долговременная память между сессиями. Модель «забывает» всё между запусками, поэтому ключевой контекст проекта хранится в папке `memory-bank/` в виде markdown-файлов:

| Файл | Назначение |
|---|---|
| `projectbrief.md` | Базовый документ: требования и цели |
| `productContext.md` | Зачем проект существует, проблемы, UX-цели |
| `activeContext.md` | Текущий фокус, недавние изменения, следующие шаги |
| `systemPatterns.md` | Архитектура, ключевые технические решения, паттерны |
| `techContext.md` | Технологии, настройка окружения, ограничения |
| `progress.md` | Что работает, что осталось, известные проблемы |

Режим работы задаётся настройкой **Memory bank** в Settings:

- **Disabled** — банк памяти не используется;
- **Tool** — агенту доступны инструменты `read_memory` (прочитать все файлы банка) и `update_memory` (записать файл банка);
- **Convention** — банк читается и обновляется обычными файловыми инструментами.

Кнопка **Memory bank** внизу вкладки Chat подставляет агенту команду обновить банк памяти проекта.

## Связанные настройки

| Поле | Назначение | По умолчанию |
|---|---|---|
| **Context window (tokens)** | Размер контекстного окна модели | `409600` |
| **Compact threshold (0..1)** | Порог заполнения для запуска автосжатия | `0.85` |
| **Reserve fraction (0..1)** | Резерв окна под ответ модели | `0.12` |
| **Keep recent messages** | Несжимаемые последние сообщения | `6` |
| **Tool result max chars** | Максимум символов результата инструмента | `12000` |
| **Auto-compact (summarize)** | Автосжатие при приближении к лимиту | вкл. |
| **Input price ($/1M tokens)** | Цена входных (некэшированных) токенов | `0.27` |
| **Cache-hit price ($/1M tokens)** | Цена кэшированных токенов | `0.07` |
| **Output price ($/1M tokens)** | Цена выходных токенов | `1.10` |
| **Memory bank** | Режим банка памяти (Disabled / Tool / Convention) | Disabled |

Полный список настроек — в разделе [Вкладка Settings](05-settings.md).
