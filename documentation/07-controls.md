# 7. Вкладка Controls (скрытая)

Вкладка **Controls** — служебная галерея для отладки интерфейса. По умолчанию скрыта.

## Как включить

1. Откройте вкладку **Settings**.
2. Включите флажок **Show controls**.
3. Нажмите **Save settings**.
4. В главном окне появится вкладка **Controls**.

## Вложенные вкладки

### Notifications

Предназначена для проверки всплывающих уведомлений расширения.

- **Auto-hide (s) — 0 = never** — через сколько секунд автоматически скрывать уведомления (`0` — не скрывать никогда).
- **Replay** — повторно воспроизводит список уведомлений.

### Chat

Содержит образцы сообщений чата (демонстрация всех видов сообщений: ответы Plan/Act, вызовы инструментов, вопросы, diff-правки и т.д.).

### SVG

Галерея иконок Material Icons, используемых в интерфейсе:

- **поле поиска** — фильтр иконок по идентификатору;
- **карточка иконки** — показывает саму иконку и её идентификатор;
- кнопка **Copy identifier** — копирует идентификатор иконки в буфер обмена;
- кнопка **Add to chat input** — добавляет идентификатор иконки в поле ввода чата.

> ⚠️ Вкладка Controls предназначена для отладки и разработки; в обычной работе её можно оставить выключенной.
