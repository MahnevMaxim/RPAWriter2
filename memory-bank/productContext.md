# Product Context

## Why this project exists
Разработка RPA-роботов на Workflow Foundation трудоёмка: нужно вручную читать ТЗ, проектировать workflow, писать XAML/C#. RPA Writer автоматизирует этот цикл через AI-агента прямо в Visual Studio.

## Problems it solves
- Ручная декомпозиция ТЗ на задачи.
- Повторный поиск похожих решений между проектами.
- Генерация шаблонного XAML/C#-кода роботов.
- Обратная инженерия существующих роботов (UiPath → WF).

## UX goals
- Один окно агента: чат + спецификация + база знаний + настройки.
- Явное разделение Plan (безопасно) и Act (с изменениями) — пользователь всегда контролирует изменения.
- Понятный индикатор заполнения контекстного окна и автосжатие без потери ключевых решений.
