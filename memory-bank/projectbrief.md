# Project Brief

RPA Writer — расширение Visual Studio, реализующее AI-агента для разработки RPA-роботов на Windows Workflow Foundation.

## Core requirements
- Читать технические задания (Word/Excel/текст) и нормализовывать их в `SpecModel`.
- Декомпозировать задание на атомарные задачи (`TaskDescriptor`).
- Генерировать робота: XAML (стандартные WF-активности) + C#-хелперы.
- Вести базу знаний переиспользуемых решений и искать похожие задачи.
- Конвертировать UiPath-роботов (XAML) в обычный Workflow Foundation.
- Чат-агент с двумя режимами: Plan (только чтение/анализ) и Act (изменения/сборки).
- Управлять контекстным окном модели (auto-compact, восстановление при переполнении).
- Долговременная память между сессиями через Memory Bank.

## Goals
- Автоматизировать рутинную разработку RPA-роботов из ТЗ.
- Единый агент, работающий поверх любого OpenAI-совместимого провайдера.
